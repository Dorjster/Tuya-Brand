# Tuya Brand · Бараа бэлтгэх, импортлох загвар

## Зургаа дахин бэлтгүүлэх

Шинэ барааны зургуудаа энэ Markdown файлтай хамт хавсаргаад дараах хүсэлтийг ашиглана.

> Эдгээр зургаар Tuya Brand-д импортлох бараа бэлд. Зураг бүрт зөвхөн хувцсыг харуул. Хүн, нүүр, бие, гар, загвар өмсөгч, харагдах манекен, бичиг нэмэхгүй. Эх зурагт харагдсан үндсэн өнгө, эсгүүр, энгэр, хээ, эмжээр, товчийг хадгал. Нэг төрлийн дэвсгэр, гэрэлтэй 1–4 JPG, PNG эсвэл WebP файл гаргаж, 01–04 гэж дараалуул. Зураг тус бүр аль өнгөтэй тохирохыг тэмдэглэ. Дараах `tuya-product` блоктой нэг Markdown файл бэлд. Өгөгдөөгүй үнэ, хэмжээ, материал, үлдэгдлийг бодит мэдээлэл гэж бүү бич. Түр утга оруулсан бол тусад нь тэмдэглэ.

Урдаас авсан зураг нүүр зураг болно. Барааны ар тал, материалын нэр эсвэл хэмжээг зурагнаас баттай мэдэх боломжгүй бол баталгаажтал хоосон орхино. Жишээ үнийг доор оруулсан. Импортлохоос өмнө бодит үнээр солино.

## Админд импортлох

1. **Админ → Бараа нэмэх → Markdown-аар мэдээлэл оруулах** хэсгээс энэ файлыг сонгоно.
2. **Барааны зураг** дээр 01–04 гэсэн дарааллаар файлуудаа сонгоно. Урьдчилсан зураг дээр дугаар нь харагдана.
3. Нэр, үнэ, үлдэгдэл, өнгө болон зурагтай холбогдсон дугаарыг шалгана. **Бараа хадгалах** дарвал ноорог үүснэ. Нийтлэхдээ **Дэлгүүрт харуулах**-ыг тэмдэглэнэ.

Үнэ нь ₮-өөр бичсэн бүхэл тоо. Хямдрал байхгүй бол `sale_price`-ийг `null` хэвээр үлдээнэ. Өнгө тус бүрийн `photo` нь **1–4** дугаар эсвэл `null` байна. Цөөн зурагтай үед байгаа дугаарыг л ашиглана. Өнгө сонгох шаардлагагүй бол `"colors": []` гэж өгнө.

| Код | Өнгө | Код | Өнгө |
| --- | --- | --- | --- |
| `red` | Улаан | `blue` | Хөх |
| `black` | Хар | `copper` | Хүрэн |
| `white` | Цагаан | `cream` | Шаргал |
| `green` | Ногоон | `gray` | Саарал |
| `pink` | Ягаан | `purple` | Нил ягаан |
| `light-blue` | Цэнхэр | `yellow` | Шар |
